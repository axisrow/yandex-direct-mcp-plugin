# yandex-direct-mcp

Управляйте Яндекс.Директом из Claude Code, ChatGPT или любой LLM — через промпты.

Не нужны сервисы за 5–50 тыс. ₽/мес. Не нужно разбираться в сложных интерфейсах. Напишите промпт — нейросеть сама соберёт статистику, поменяет ставки, отключит дорогие объявления и пришлёт понятный отчёт.

Open-source · бесплатно · работает локально

## Быстрый старт

**1. Подключите маркетплейс** (один раз):

```
/plugin marketplace add etopro/plugin-marketplace
```

**2. Установите плагин:**

```
/plugin install yandex-direct@plugin-marketplace
```

**3. Авторизуйтесь** в Яндексе:

```
auth_login()
```

Откроется браузер → войдите в Яндекс → токен сохранится автоматически.

**4. Готово.** Пишите промпт:

```
Покажи кампании за последнюю неделю, отключи объявления,
где заявка дороже 1500 ₽, а там, где дешёвые — подними бюджет на 20%.
```

> Перед первой авторизацией нужно один раз [создать приложение Яндекс](#создание-приложения-яндекс).

## Что умеет

- **Кампании** — просмотр, создание, редактирование, включение/отключение, архивация
- **Мастера кампаний** — read-only просмотр по ID, включая статусы модерации и целевые действия
- **Объявления** — текстовые, динамические, смарт-объявления, видеодополнения
- **Ставки и бюджеты** — ручные и автоматические ставки, лимиты, корректировки
- **Ключевые слова** — подбор, дедупликация, проверка объёма, минус-слова
- **Отчёты** — произвольные отчёты, статистика по конверсиям с целями Метрики
- **Финансы** — баланс, пополнение, выставление счетов, переводы между аккаунтами
- **Справочники** — регионы, валюты, площадки
- **Написание объявлений** — скилл, который умеет писать объявления под требования Директа

Всего 151 инструмент. Полный список: [`docs/TOOLS.md`](docs/TOOLS.md).
В чате: `tool_help()` — все инструменты, `tool_help('campaigns_get')` — справка по конкретному.

## Безопасность

Плагин работает только на вашем компьютере. Токен и данные аккаунта не уходят на чужие серверы. Исходный код открыт — можно проверить.

Все изменения требуют подтверждения: нейросеть покажет, что собирается сделать, и дождётся вашего «ок».

`masters_get` и `masters_targetactions_get` работают только на чтение и через
браузерный интерфейс Директа: у Мастеров кампаний нет Management API. Для них
нужна отдельная браузерная сессия (OAuth-профиль API её не заменяет). Один раз
выполните в терминале `direct masters login`; мутационные команды `direct
masters add/update/delete/copy/archive/suspend/resume/launch` плагин не
предоставляет.

## Настройка инструментов

По умолчанию доступен весь 151 инструмент. Можно ограничить набор через переменные окружения:

| Переменная | Что делает |
|---|---|
| `YANDEX_DIRECT_TOOL_PROFILE` | Пресет: `full` (по умолчанию), `core` (10), `analytics` (26), `campaign-editor` (36) |
| `YANDEX_DIRECT_ENABLED_GROUPS` | Включить только эти группы |
| `YANDEX_DIRECT_DISABLED_GROUPS` | Исключить группы |
| `YANDEX_DIRECT_ENABLED_TOOLS` / `_DISABLED_TOOLS` | Точечные переопределения |

```jsonc
// ~/.claude/settings.json — только аналитика
{ "env": { "YANDEX_DIRECT_TOOL_PROFILE": "analytics" } }
```

Подробнее: [`docs/token-budget.md`](docs/token-budget.md).

## Создание приложения Яндекс

Делается один раз перед первой авторизацией.

### Шаг 1. OAuth-приложение

1. Откройте https://oauth.yandex.ru/client/new
2. Заполните:
   - **Название** — любое (например, `My Direct Plugin`)
   - **Платформа** — «Веб-сервисы»
   - **Redirect URI** — `https://oauth.yandex.ru/verification_code`
   - **Доступы** — добавьте **«Использование API Яндекс Директа»** (`direct:api`)
3. Сохраните **Client ID** и **Client Secret**

### Шаг 2. Заявка на доступ к API

1. Войдите в https://direct.yandex.ru → **Инструменты → API → Мои заявки**
2. Нажмите «Новая заявка», укажите Client ID из Шага 1
3. Дождитесь подтверждения

> Без Шага 2 все запросы вернут ошибку `incomplete_registration`.

### Использование своего OAuth-приложения

```bash
direct auth login --client-id "ваш-client-id" --client-secret "ваш-client-secret"
```
