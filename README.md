# yandex-direct-mcp-plugin

Плагин для Claude Code, который даёт доступ к Яндекс.Директ прямо из чата.
Кампании, объявления, ставки, отчёты, аналитика — всё через естественный язык.

## Установка

### Claude Code (рекомендуется)

```
/install axisrow/yandex-direct-mcp-plugin
```

Плагин установится из маркетплейса, подтянет зависимости и запустит MCP-сервер автоматически.

### Codex

Маркетплейс-манифест: `.agents/plugins/marketplace.json`. Плагин-бандл: `plugins/yandex-direct/`.

### Для разработки

```bash
git clone https://github.com/axisrow/yandex-direct-mcp-plugin.git
cd yandex-direct-mcp-plugin
pip install -e ".[dev]"
python -m server.main  # запуск MCP-сервера
```

## Аутентификация

Плагин не хранит токены — за авторизацию отвечает [`direct-cli`](https://github.com/axisrow/direct-cli).

**OAuth (интерактивно)** — самый простой способ:

```
auth_login()
```

Откроется браузер, вы авторизуетесь в Яндексе, токен сохранится автоматически.

**Готовый токен** — если уже есть OAuth-токен:

```
auth_setup(code="y0_AgAAAA...", login="ваш-логин")
```

**Проверить статус:**

```
auth_status()
```

> Перед первой авторизацией нужно [создать приложение Яндекс](#создание-приложения-яндекс) — это делается один раз.

## Что умеет (146 инструментов)

- **Кампании** — просмотр, создание, редактирование, включение/отключение, архивация
- **Объявления** — управление текстовыми, динамическими, смарт-объявлениями
- **Ставки и бюджеты** — ручные и автоматические ставки, лимиты, корректировки
- **Ключевые слова** — подбор, дедупликация, проверка объёма, минус-слова
- **Отчёты и аналитика** — произвольные отчёты, статистика, цели Метрики
- **Аудитории** — ретаргетинг, аудиторные таргеты
- **Справочники** — регионы, валюты, площадки
- **Финансы** — баланс, пополнение, переводы (v4 Live API)
- **Скиллы** — доменные знания для управления рекламой и написания объявлений

Полный список инструментов: [`docs/TOOLS.md`](docs/TOOLS.md).
Внутри чата: `tool_help()` — список всех, `tool_help('campaigns_get')` — справка по конкретному.

## Примеры

Просто пишите на естественном языке:

```
> покажи активные кампании
> сколько объявлений в кампании 12345?
> отключи кампанию 67890
> поставь ставку 15 руб на ключевое слово 99999
> статистика за последнюю неделю
> баланс аккаунта
> напиши объявление для доставки пиццы
> токен живой?
```

> **Деньги в микроюнитах:** 15 руб = 15 000 000. Плагин конвертирует автоматически.

## Настройка инструментов

По умолчанию доступны все 146 инструментов. Если хотите ограничить набор — задайте профиль или группы через переменные окружения:

| Переменная | Что делает |
|---|---|
| `YANDEX_DIRECT_TOOL_PROFILE` | Пресет: `full` (по умолчанию), `core` (10), `analytics` (28), `campaign-editor` (35) |
| `YANDEX_DIRECT_ENABLED_GROUPS` | Включить только эти группы (сервисы, действия, области) |
| `YANDEX_DIRECT_DISABLED_GROUPS` | Исключить группы |
| `YANDEX_DIRECT_ENABLED_TOOLS` / `_DISABLED_TOOLS` | Точечные переопределения (через запятую) |

```jsonc
// ~/.claude/settings.json — только аналитика
{ "env": { "YANDEX_DIRECT_TOOL_PROFILE": "analytics" } }
```

Подробнее о группах и бюджете токенов: [`docs/token-budget.md`](docs/token-budget.md).

## Создание приложения Яндекс

Делается один раз перед первой авторизацией.

### Шаг 1. OAuth-приложение

1. Откройте https://oauth.yandex.ru/client/new
2. Заполните:
   - **Название** — любое (например, `My Direct Plugin`)
   - **Платформа** — «Веб-сервисы»
   - **Redirect URI** — `https://oauth.yandex.ru/verification_code`
   - **Доступы** — добавьте **«Использование API Яндекс Директа»** (`direct:api`)
3. Сохраните **Client ID** и **Client Secret**

### Шаг 2. Заявка на доступ к API

1. Войдите в https://direct.yandex.ru → **Инструменты → API → Мои заявки**
2. Нажмите «Новая заявка», укажите Client ID из Шага 1
3. Дождитесь подтверждения

> Без Шага 2 все запросы вернут ошибку `incomplete_registration`.

### Использование своего приложения

```bash
direct auth login --client-id "ваш-client-id" --client-secret "ваш-client-secret"
```
